# A 股重仓风险监控 (Showcase)

一位**重仓中际旭创的 A 股投资者**（虚构演示 persona）的风险 watch，由
portfolio-watch skill 从一句话构建：中际旭创 3,000 股（约 64%，重仓）、
新易盛 1,000 股、天孚通信 1,000 股、贵州茅台 100 股、现金 ¥66 万；
自报目标仓位 50/10/10/5/25，诉求："光模块涨太多了，我怕板块一起回调。"

## 第一性原理设计

1. **风险的单位是敞口，不是代码。** 五个仓位实际上只有约 **1.6 个有效押注**
   （1/Σw²，板块内相关性 ~0.68）——集中的是相关性，不只是仓位。这是页面的
   第一个数字。
2. **收益分解，信号在残差。** 每只光模块股的 β/残差按**簇内 leave-one-out
   基准**计算（该股基准 = 其余同业等权均值）："中际旭创是跟着板块动，还是
   自己出事"正是重仓者要的分解。平台暂无 A 股指数数据 → 板块基准而非市场
   基准，如实声明。板块同向 ≥3σ 且高相关 → **合并为一条板块事件**。
3. **A 股语义是一等公民。** 创业板 ±20% / 主板 ±10% **涨跌停 = critical 告警**
   （T+1 下是流动性事件）；**超出限价的"涨跌"物理上不可能是交易** → 判定为
   除权除息/送转：该日静默 + 提示核对股数，滚动统计中除权日收益归零。
   交易时段 09:30–15:00 CST（含午休，会话状态数据驱动）；CST 无夏令时，
   调度窗口全年不漂移。
4. **每条告警指明它服务的决策**——用户自设的目标带、待验证的论点、风险
   限额——绝不给交易指令。
5. **规则必须可证伪。** 页面内嵌 12 个月确定性回放。构建期它完成了两次证伪：
   带边震荡（→滞回修复）、未复权数据把除权日误判成"跌停 −33.9%"（→除权
   识别修复）。修复后回放显示这本账过去一年**真实经历了 −20% 级回撤**——
   persona 的担忧被历史坐实，而规则会在回撤加深的每一档提醒他。

## 告警规则（preset: normal）

| 规则 | 阈值 | 服务的决策 |
|---|---|---|
| 板块同向 | 簇内 ≥2 只同向 ≥3σ 且相关性 ≥0.5 → 一条 | 看回撤限额，不逐票反应 |
| 板块残差 | ≥3× 该股 60 交易日残差 σ | 重新检查该票论点 |
| 涨跌停 | ±20%（创业板）/±10%（主板）触板 | T+1 流动性事件，核对仓位计划 |
| 除权除息 | \|涨跌\| 超限价 +2pp（未复权价源） | 无需行动；更新股数 |
| 漂移 | 权重出目标带 ±5pp（回带内 1pp 重武装） | 再平衡决策点 |
| 回撤 | −5/10/15/20/30% 事件化，进入与加深才报 | 风险限额检查 |
| 有效押注数 | 跌破 2.0 | 分散度检查 |
| 量能 / 跳空 | 收盘 ≥3× 20 日均量 / 开盘 ≥2σ | 关注信号 / 隔夜传导 |

每次运行至多一条 digest，按严重度排序，带"打开 Playbook"按钮；novelty
gate 压重复，仅升级重报。

## 诚实声明

持仓为用户申报并自行维护（送转后需更新股数）；不编造成本价；财报日历
数据仅覆盖美股（A 股财报期提醒缺席，已列盲区）；分红收益未建模（回放
NAV 偏保守）；单一板块基准，非市场基准。**虚构演示数据，不构成投资建议。**
