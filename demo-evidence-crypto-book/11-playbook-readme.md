# 加密申报账本监控（Crypto Book Demo）

一位 BTC 重仓投资者的**申报加密账本**（虚构演示 persona）：0.75 BTC、6 ETH、
160 SOL、18,000 USDT，目标仓位 40/25/20/15。每小时刷新，24/7——加密市场
没有收盘，每一次运行都是一次判断。

## 它盯什么

- **快慢两条车道**：24 小时滚动变化（20 自然日 σ 标定）+ 1 小时急动
  （7 日小时 σ 标定，方向状态制——持续下跌只在开始提醒一次，不逐小时轰炸）。
- **敞口而非代码**：BTC/ETH/SOL 高相关，同向大动合并为一条大盘事件；
  单币声音只属于残差（扣 β 后 ≥3× 残差 σ 且自身 ≥1σ 在动）。
- **稳定币纪律**：USDT 按 1 计值、永不产生波动告警；脱锚经 USDC/USDT
  交叉盘监控，连续两次运行确认才告警（≥0.5% warning / ≥1% critical）。
- **状态化组合风险**：目标带 ±5pp 漂移（滞回重武装）、回撤 −5/10/15/20/30%
  episode（进入/加深才响，恢复静默复位）、有效押注数 < 2.0 提示。

## 更新节奏与数据

每小时（cron `0 * * * *`，UTC）。价格来自 Binance 现货 USDT 对
（USDT≈USD 标注）；页面每个数字打开时现读，不缓存、不硬编码。

## 阈值一览（preset: normal）

| 规则 | 阈值 | 严重级 |
|---|---|---|
| 24h 波动 | ≥3σ / ≥6σ | warning / critical |
| 1h 急动 | ≥5× 小时 σ / ≥7.5× | warning / critical |
| 大盘残差 | ≥3× 残差 σ（自身 ≥1σ） | warning / critical |
| 大盘联动 | ≥2 币同向 ≥3σ、相关性 ≥0.5 | 合并为一条 |
| 脱锚 | 偏离 ≥0.5%（两次确认）/ ≥1% | warning / critical |
| 目标带 | ±5pp（回带 1pp 重武装） | info |
| 回撤 | −5/10/15/20/30% 档进入/加深 | warning / ≥15% critical |
